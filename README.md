# simple-Voice-AI-Project
A very simple Python project: an AI that uses Ollama to conduct a voice conversation with the AI.

Hello! This is my first artificial intelligence project. While I have published other projects previously, this is the first AI project I have created.
I built it using Ollama. It is a very simple project that operates by activating the microphone, performing Speech-to-Text (STT), sending a message to the local Ollama instance, generating a Text-to-Speech (TTS) response, and finally playing the audio output.
